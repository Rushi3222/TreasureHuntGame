# Treasure Hunt: Interactive Puzzle Adventure

A first-person puzzle-adventure game developed using **Unreal Engine 5, C++, and Blueprints**, focused on environmental interactions, puzzle solving, and exploration.

## Overview

The project involves building interactive gameplay systems in which players solve environmental puzzles to unlock hidden areas and progress through the game. It combines C++ gameplay programming with Blueprint-based event logic.

## Features

- **Pressure-Plate Puzzles:** Develops puzzle interactions that activate mechanisms.
- **Hidden-Door Mechanisms:** Connects puzzle interactions to door-opening events.
- **Interactive Objects:** Builds reusable gameplay components for pickups, trigger buttons, and locks.
- **Event-Driven Gameplay:** Uses triggers and gameplay events to connect interactions with level progression.
- **C++ and Blueprint Integration:** Combines C++ components with Blueprint logic to build gameplay systems.

## Technologies

- Unreal Engine 5
- C++
- Blueprints
